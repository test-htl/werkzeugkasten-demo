# Team-Werkzeugkasten

Übungsprojekt für Scrum mit GitHub. Jedes Teammitglied baut ein kleines Werkzeug.

## Starten

Den Ordner in VS Code öffnen und `index.html` mit der Erweiterung „Live Server“ starten.
Ohne Erweiterung: `index.html` per Doppelklick im Browser öffnen.

## Aufbau

- `index.html`: Startseite mit Slogan und Liste der Werkzeuge
- `style.css`: gemeinsames Aussehen
- `tools/zaehler/`: fertiges Beispiel als Vorbild
- `AGENTS.md`: Regeln für KI-Werkzeuge
- `CONTRIBUTING.md`: der Ablauf einer Story in zehn Schritten
